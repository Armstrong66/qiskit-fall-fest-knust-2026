# Contributing to Qiskit Fall Fest KNUST 2026

We welcome contributions, tutorial notebooks, and documentation improvements from chapter members and the broader community.

## How to Contribute
1. Fork the repository and create your branch from `main`:
   ```bash
   git checkout -b feature/workshop-notebook-update
   ```
2. For website changes, work inside the `web/` directory and test locally:
   ```bash
   cd web
   npm run dev
   ```
3. For workshop materials, place your slides (`.pdf`) or Jupyter notebooks (`.ipynb`) in the relevant subfolder under `workshops/`.
4. Ensure notebooks are cleared of excessive output before committing.
5. Submit a Pull Request describing your changes clearly.
